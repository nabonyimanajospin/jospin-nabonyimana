Welcome to a professional collection of **Java-based console applications** built with **Object-Oriented Programming (OOP)**. These projects demonstrate real-world system simulations with modular code, clean structure, and effective input validation.

## 📁 Included Projects

### 🛒 1. Advanced Online Shopping System

A smart shopping simulation where users can:
- Browse multiple product categories
- Add items to cart with quantity & stock checks
- Process validated payments (Cash, Credit, Mobile Money)
- Generate receipts and summaries

**Key Concepts:**
- Abstract Product superclass with 5 subclasses (Phone, Shirt, Book, etc.)
- Cart and Payment system with validation
- Customer data encapsulation
- Menu-driven interaction via `Scanner`

> 🔧 Technologies: Java, Scanner, OOP, Abstraction, Polymorphism

### 📦 2. Advanced Stock Management System

A robust inventory system allowing:
- Add/Edit/Delete/View stock items
- Quantity & price control
- Low-stock alerts
- Inventory report generation

**Key Concepts:**
- `StockItem` class with encapsulated properties
- Admin console with choices
- Real-time stock updates

> 🔧 Technologies: Java, Modular Classes, Menu Interface, Validation

### 🚗 3. Motor Vehicle Management System

A management solution for vehicles and owners:
- Register vehicles with validated info
- Track service history
- View/update vehicle data by license plate
- Owner & vehicle linkage

**Key Concepts:**
- Vehicle superclass with subclasses (Car, Motorcycle, Truck)
- Service record tracking
- Encapsulated owner details
- Search and reporting features

> 🔧 Technologies: Java, Inheritance, Encapsulation, Scanner I/O


## 🎯 OOP Principles Used

| Principle    | Applied In                                |
|--------------|-------------------------------------------|
| Abstraction  | Product & Vehicle base classes            |
| Inheritance  | Product types, Vehicle types              |
| Encapsulation| Customer, Owner, StockItem, Cart classes  |
| Polymorphism | Payment system, Product methods           |

## 🚀 How to Run Locally

```bash
# Step 1: Compile the Java code
javac Main.java

# Step 2: Run the program
java Main
```
> 📌 Make sure to `cd` into the correct project directory and replace `Main.java` with the actual main class name.
